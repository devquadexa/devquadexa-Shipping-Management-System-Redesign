## 1. THE PRODUCT — Simple & Clear

**Q: What problem does this cargo management software solve in one sentence?**
A: Real-time cargo tracking software that eliminates manual spreadsheets, automates shipping workflows, and cuts cargo handling time by tracking every container from arrival to customer delivery with zero lost shipments.

**Q: Explain it like you're explaining to a traditional logistics manager with no tech background.**
A: Instead of using WhatsApp, Excel sheets, and handwritten notes to track 50+ containers, you get ONE dashboard where every shipment is visible in real-time. Update status once, everyone sees it instantly. Billing is automatic. Payment tracking is clear. No more "where is my cargo?" calls.

**Q: What happens step by step from the moment a shipment arrives to the final cargo gate-out/delivery?**
A:
1. Container arrives → Manager creates Job in system (enters BL#, CUSDEC#, Container#)
2. System auto-assigns to appropriate team based on location (Colombo → Colombo team)
3. All assigned team members see it on dashboard instantly with notification
4. Warehouse staff update status: "In Progress" (all see live update in seconds)
5. Documentation tracked: CUSDEC approval, customs clearance, export details
6. Manager creates bill automatically when work is complete
7. Customer receives bill and pays (Cash/Cheque/Bank Transfer recorded)
8. Status updated to "Payment Collected" then "Completed"
9. Final notification sent: "Your cargo is ready for pickup"
10. Report generated automatically for accounting

**Q: What is the one feature no competitor offers?**
A: Multi-Role, Geographic-Intelligent Job Assignment with Real-Time Collaborative Notifications. Most systems assign to one person. This system assigns to multiple people across different districts simultaneously. When a Colombo container arrives, it auto-suggests "Colombo team" based on destination. All assigned users see it instantly with notifications. Plus integrated billing and payment tracking. No more lost cargo or duplicate work.

## 5. HOW THE DELIVERY SYSTEM WORKS

**Q: Does the app track incoming shipments in real-time?**
A: Yes. Complete live tracking with status updates appearing within seconds to all assigned team members. Status flow: Open → In Progress → Pending Payment → Payment Collected → Completed. All active shipments visible on dashboard at a glance.

**Q: How does the system automatically decide where cargo should go?**
A: Geographic & Role-Based Intelligent Assignment. Container arrives with destination (e.g., "Kandy"). System checks: Who handles Kandy shipments? Shows recommended team: Kandy Office Manager + Kandy Warehouse Staff. Manager assigns with ONE CLICK. Job appears on their dashboard instantly. Can assign to multiple people simultaneously.

**Q: Do clients get automated notifications when their shipment arrives or is completed?**
A: Yes. In-app notification system fully implemented with:
- Notifications: Job Assigned, In Progress, Ready for Pickup, Invoice Generated, Payment Received, Shipment Complete
- Notification bell with unread count, auto-refresh every 30 seconds
- Infrastructure ready for SMS (Twilio) and Email (SendGrid) integration
- Database supports customer preferences for notification channels

**Q: How are cargo handling fees and service bills tracked and paid?**
A: Complete billing system: Manager clicks "Create Bill" → auto-filled with service charges, labor, taxes → Invoice generated instantly with invoice number, date, due date, itemized breakdown. Payment Status: Unpaid → Partially Paid → Paid. Payment Methods: Cash, Cheque (with #, date, bank), Bank Transfer all tracked. Supports advance payments and partial payments.

**Q: What does the manager's screen look like?**
A: Main Dashboard shows: Active Shipments count, Pending Payment count, Ready for Pickup, Overdue alerts, Unread Notifications. Job list with filters by status, date, location. Quick action buttons: New Job, Create Bill, Record Payment, View Reports, Assign Job. Billing screen shows all invoices with status, create/edit bills, record payments, view overdue. Reports screen shows Cash Summary, Pending Payments, Transporter Payments, Petty Cash. All responsive on desktop, tablet, mobile.

## 6. HOW THE INVENTORY SYSTEM WORKS

**Q: Does cargo/container status update automatically when offloaded, moved, or cleared?**
A: Yes. Staff update status with ONE CLICK. Update appears instantly on dashboard for all assigned users. Status flow: Open → In Progress → Pending Payment → Payment Collected → Completed. Can add notes at each stage (e.g., "Unloading complete", "Customs cleared").

**Q: Are there automated alerts for cargo sitting in the yard too long (dwell time)?**
A: Yes. Dashboard shows dwell time indicators:
- Job Status Overdue: If job stays "Open" for 2+ days → Red alert
- Payment Overdue: If invoice past due date → Red flag
- Shows how many days cargo has been in each status
- One-click "Send Reminder" to customer for stuck shipments

**Q: Can it track cargo manifest details, BL numbers, CUSDEC numbers, or customs clearance status?**
A: Yes. Tracks all manifest details:
- BL Number (Bill of Lading)
- CUSDEC Number (Sri Lankan customs declaration)
- CUSDEC Date (when customs approved)
- Container Number
- Exporter
- Transporter
- LC Number (Letter of Credit)
- Chassis Number (vehicle details)
- Customs approval status: ✅ CLEARED
- All docs linked in one place

**Q: Can it manage yard space allocation, container storage locations, and gate-in/gate-out processes?**
A: Partial capability now, ready for expansion:
- Currently: Track locations by geographic district/city, assign to specific warehouses/yards
- Notes field for: "Stored in Yard A, Row 3, Stack 2"
- Gate-In: Records arrival time, condition (damaged/good), location automatically
- Gate-Out: Status "Payment Collected" required before gate-out, auto-timestamps exit, audit trail recorded
- Future enhancement: Visual yard map, automated stack balancing, real-time occupancy %
